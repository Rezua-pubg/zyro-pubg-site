# ZYRO PUBG — Metro Royale rating display

This package updates the public-facing dashboard with a Metro Royale rating table layout and the previously agreed scoring notes.

- Shows K/D, matches, PUBG MOBILE's displayed average-loot stat, points by each criterion, and Metro Custom winner bonus.
- Top 10 per criterion: 10 down to 1 point; below 10th: 0 points.
- K/D tie-break: more matches ranks higher.
- Metro Custom winner: +15 points.
- No player statistics are fabricated; the table remains empty until administrators enter verified data.
- The average-loot formula is not reproduced because PUBG MOBILE already displays that metric.
- Classic and Ultimate remain empty placeholders; their agreed criteria are not inferred here.

This is a static website preview. It is not yet connected to the admin panel or a shared backend.
