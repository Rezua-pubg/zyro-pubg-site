# ZYRO PUBG — многостраничный сайт

## Страницы
- `index.html` — главная
- `clan.html` — интерактивный состав с плавным открытием профиля игрока
- `ratings.html` — отдельные рейтинги Metro Royale, Classic, Ultimate
- `news.html` — анонсы
- `apply.html` — вступление и апелляция через существующий FormSubmit endpoint
- `admin.html` — демонстрационный макет админ-панели (не защищён и пока не записывает данные)

## Публикация через GitHub Pages
Загрузи содержимое этой папки в корень репозитория `zyro-pubg-site`, сохрани структуру `assets/`, затем Commit changes. В Settings → Pages выбери `main` и `/ (root)`.

## Supabase
Открой `assets/config.js` и укажи Project URL и **publishable** API key проекта. Никогда не помещай secret или service_role key в публичный сайт. Таблицы `announcements` и `player_ratings` в проекте уже создавались, но их политики и схема требуют проверки. Публичное чтение анонсов в `assets/site.js` рассчитано на поля `title`, `body`, `created_at`, `published`.

До публичного запуска настрой Supabase Auth для администратора, Row Level Security (RLS) и отдельные политики: публично разрешить только чтение опубликованных анонсов и рейтингов, а запись — только аутентифицированному администратору. Не включай открытые INSERT/UPDATE/DELETE политики.

## Что пока демонстрационное
- рейтинги и статистика отображают заглушки
- админ-панель не сохраняет данные
- изображения игроков используют единый фирменный SVG-образ шлема и белой рубашки
- формы используют endpoint FormSubmit `dbnqhfp4nm`; проверь доставку тестовыми заявками
