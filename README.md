ZYRO PUBG — автономная многостраничная версия сайта.
Все стили и скрипты встроены в каждый HTML-файл; внешняя папка assets не требуется.
Загрузите все HTML-файлы в корень репозитория GitHub Pages.
Важно: админ-панель демонстрационная, хранит данные только в браузере. Для публичного управления нужен backend и защищённая авторизация.
Формы заявок открывают почтовое приложение; перед отправкой нужно проверить адрес получателя.
